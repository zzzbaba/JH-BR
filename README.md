## 启动

**线上体验服：<http://zzzbaba.fun:8123/>** —— 不想自己搭就直接进这个。开发中，随时可能重启。

本地跑，双击 `start.bat`，或命令行：

```bash
node server.js
```

- 游戏：<http://127.0.0.1:8123>
- 后台：<http://127.0.0.1:8123/admin.html> （密码首次启动随机生成，见 `store/admin.json` 或启动日志；可在后台「数值」页修改）

账号密码用 scrypt 加盐哈希存储，存档为本地 JSON 文件。

## 轮次

一局是一轮。

- 标准时长 **30 分钟**。30 分钟到点时如果还有人活着，延长到 **45 分钟**硬性结束。
- 三种结束方式：**击杀最终 BOSS**、**有人带走七娃**、**所有参与者出局**。
- 结束方式还有管理员手动结束。
- **最终 BOSS 前 30 分钟不出现**。到 30 分钟时广播「广播员出现在广华寺钟楼」，谁先杀掉他谁赢。之前去钟楼只会看到空楼。
- 一轮结束后不会自动开下一轮，需要有人在等待页点「加入对局」（第一个玩家会触发开轮），或管理员在后台点「开始新一轮」。
- 一轮结束后所有角色作废，下一轮重新抽签。

## 地图

8×8 共 64 个区块，四个片区：

| 片区  | 区块数 | 位置      |
| --- | --- | ------- |
| 广华  | 20  | 西北      |
| 向阳  | 20  | 中部      |
| 五七  | 20  | 东南      |
| 十号地 | 4   | 正中（出生地） |

区块名全部取自江汉油田真实地名。危险度按「离十号地的曼哈顿距离」递进：出生地 1，相邻 2，往外 3/4，最边缘 5。

**广华寺（地图西北角）是最终 BOSS 所在地。**

## 核心循环

1. 点相邻格子移动（−4 精力），或点当前格探索（−3 精力）
2. 每次移动/探索掷一次事件：
   - **遭遇**（战斗 / 放我一马 / 使用道具）
   - **人质**（敌人 + 被绑的人，打赢后可以问她愿不愿意跟你走）
   - **七娃**（8 岁男孩，20% 概率跟你走，带走即本轮胜利）
   - **刘颖**（红蓝药丸 + 一道题，随机增益或减益）
   - **宝箱** / **地雷** / **剧情 NPC**
3. 战斗：攻击 / 使用道具 / 换武器 / 防御 / 逃跑
4. 打赢了捡尸体上的东西

**血量和精力任意一项归零，游戏结束。**

## 界面上的数值

状态卡片顶部是血条和精力条，下面是四个实战数值（都已计入当前装备和状态）：

| 数值 | 算法                          |
| -- | --------------------------- |
| 攻击 | 当前武器伤害 ×(1+武力/150) × 状态系数   |
| 防御 | 六件防具防御之和 × 状态系数             |
| 命中 | 82% + 幸运×0.12 + 配件加成 − 状态惩罚 |
| 暴击 | 8% + 幸运×0.25                |

属性面板每一行右边跟着这项属性的实际产出：

- 体力 → 血量上限
- 武力 → 攻击
- 魅力 → 交涉成功率
- 智力 → 合成成功率
- 幸运 → 暴击率

装备面板底部显示已穿件数、装备防御合计、计入状态后的实际防御。属性数字变绿表示有增益，变红表示被减益。

## 道具悬浮说明

鼠标停在**背包、装备栏、商店、战利品、宝箱、合成、交易**里的任何物品上，都会弹出详细说明：

- 名称、类型、描述
- 关键数值（伤害/噪音/防御/容量/回血/状态效果…）
- **和当前穿戴的同类装备做对比**：绿色 `↑` 表示更好，红色 `↓` 表示更差，`=` 表示持平
- 武器会提示噪音高低的后果，药物会写明状态效果和解除范围
- 材料会列出用到它的所有配方
- 弹药会列出适配的枪械

新手不用查表，把鼠标放上去就知道该不该换。

## 等级

击杀敌人给经验，不同危险度给的量不同：

| 敌人等级    | 经验  |
| ------- | --- |
| tier 1  | 15  |
| tier 2  | 30  |
| tier 3  | 50  |
| tier 4  | 75  |
| tier 5  | 110 |
| 最终 BOSS | 500 |

升级需求 = `40 + (等级-1) × 18`。每升一级五维各 +2%（至少 +1），并回复 15 血、10 精力。

**上限 30 级**。属性到 100 后锁死，升级也不会突破——和属性上限规则一致。

## 五维属性

| 属性 | 作用                  |
| -- | ------------------- |
| 体力 | 血量上限（55 + 体力×1.8）   |
| 武力 | 攻击伤害倍率              |
| 魅力 | 「放我一马」成功率、人质带走成功率   |
| 智力 | 合成成功率               |
| 幸运 | 命中、暴击、高价值掉落、地雷减伤、逃跑 |

- 初始每项随机 8–18，**上限 100**
- 任一项到 100 后，**其他属性永久无法再提升**（系统会提示）
- 该项对应的功能也会达到 100% 成功（智力 100 时合成必成）

## 天气系统

全局天气，每 7–10 分钟自动切换，切换时会在公共频道广播。顶栏实时显示当前天气。

| 天气 | 影响 |
|---|---|
| 晴 / 阴 | 无 |
| 大风 | 攻击 −10%，命中 −8，声音传得更远 |
| 暴雨 | 移动更耗精力（×1.4），命中 −5，但雨声盖住枪声 |
| 大雾 | 命中 −15，但也更不容易被人撞见（遭遇率 ×0.7） |
| 沙尘 | 攻击 −5%，命中 −10，移动更耗精力 |

天气同时影响**实际战斗**和**界面显示的数值**，看到的就是打出来的。

## 空投补给

每 7–11 分钟随机一个区块掉落补给箱，全服广播位置。5 分钟内到那个区块探索，必出一次宝箱。区块信息栏会亮「空投」标记。

## 状态系统

人物同时只保留一个状态，默认「正常」。新状态覆盖旧状态，**每个状态持续 5 分钟**。

| 状态   | 效果                        | 怎么获得    |
| ---- | ------------------------- | ------- |
| 喝醉了  | 防御 ×1.5，攻击 ×0.7，命中 −10    | 二锅头     |
| 非常清醒 | 防御 ×1.25，攻击 ×1.25，命中 +8   | 黑咖啡     |
| 中毒了  | 每次移动/探索，当前血量和精力各掉 20%     | 毒蘑菇     |
| 冷冻麻痹 | 10 秒内不能换图，防御 ×0.9，攻击 ×0.8 | 液氮罐     |
| 正常   | 无                         | 默认 / 解除 |

解除道具：**解毒剂**（解中毒）、**醒酒汤**（解醉酒）、**万能解药**（清所有状态）。

状态类道具在商人处能买到一部分（二锅头、黑咖啡、解毒剂、醒酒汤），毒蘑菇、液氮罐、万能解药只能从尸体和箱子里翻。

## 武器耐久与改装

每把武器有耐久。攻击时不管中没中都磨损：

| 类型           | 最大耐久 | 每次消耗 |
| ------------ | ---- | ---- |
| 火箭筒          | 3    | 1    |
| 冷兵器          | 70   | 1    |
| 狙击枪          | 80   | 2    |
| 手枪/步枪/冲锋枪/霰弹 | 100  | 2    |
| 机枪           | 150  | 3    |

耐久归零武器就废了，攻击自动改成徒手（不会卡住）。修复方式两种：

- **修理包** +40 耐久（配方：废铁 + 机油 + 胶带）
- 找「修车的老韩」（广南新村）花 40 块修满

**改装**只有火器能改，三个槽位：

| 槽位 | 配件   | 效果     |
| -- | ---- | ------ |
| 瞄具 | 瞄准镜  | 命中 +12 |
| 枪口 | 消音器  | 噪音 −6  |
| 握把 | 战术握把 | 伤害 +8% |

配件从背包消耗，换武器或卸下时**自动拆回背包**，不会丢。

## 常驻 NPC

8 个 NPC 固定待在特定区块，可以反复交谈：

| 位置    | NPC   | 特色            |
| ----- | ----- | ------------- |
| 广南新村  | 修车的老韩 | 修武器、卖修理包和配件   |
| 五场    | 小学老师  | 情报、地图、医疗      |
| 五七厂   | 女工    | 瞄准镜、消音器       |
| 龙湾镇   | 老中医   | 解毒剂、万能解药      |
| 采油一队  | 采油工   | 各类弹药          |
| 化工厂   | 疯子    | 炸弹、闪光弹        |
| 姚嘴    | 老船夫   | 止血带、对讲机       |
| 油田公安局 | 看守    | 子弹、防刺服（好感要求高） |

每次交谈 +1 好感，有 3–5 回合冷却（防刷）。好感达到阈值会主动给你东西，到 4–5 能买到更好的货。NPC 不和商人在同一个区块。

**人质**：遭遇战时可能遇到敌人守着一个人。打赢后可以问她愿不愿意跟你走。

**结果用表情给，不用文字先说**：问完之后她先低头沉默，1.3 秒后表情变化——**眼睛亮起来**就是同意了，**头低下去、闭眼**就是拒绝了。然后才出文字和「继续」。

带走的人质会跟着你，心情分开心 / 一般 / 不开心。**心情开心时**才能「挑逗」她——20% 成功，她会给你唱首歌或讲个故事（每次 +5 排名分）。累计带走 10 个解锁「人质救星」。

区域栏常显「黑市 某某地 04:08」，不用记播报也能找到它。

**三倍价**，只卖平时买不到的高级武器：

| 武器 | 黑市价 |
|:---|---:|
| 56式半自动步枪 | 660 |
| 95式自动步枪 | 780 |
| 95式班用机枪 | 900 |
| 双管猎枪 | 1020 |
| 88式狙击步枪 | 1260 |

西大垸（危险 2）常年蹲着一个佣兵头子，地图上是**蓝点**。只管雇人，不卖东西。

| 价位 | 名号 | 攻 | 血 |
|:---|---:|---:|---:|

## 结算战报

每轮结束时结算页会给你三行：

```
第 7 回合，你在楼道里第一次和人正面撞上，活了下来。
第 18 回合，动静太大，前后围上来两个。
最后，钟楼上那一关没过去。
```

数据来自 `c.keyLog`（首杀 / 第一把枪 / 被围 / 死亡地点与凶手），
和 `c.log` 分开存——log 是 120 条流水会被冲掉，keyLog 只留能写进战报的。

## 假人

后台「玩家」页可以投放假人，**上限 50 个**。

假人不是站着不动的装饰：它们直接调 `G.act`，跟真人走完全相同的逻辑——
会探索、会遭遇、会打架、会捡东西、会升级、会死。血少了吃药，精力空了休息，
空手会先装武器，走位按「物资×2 + 危险」加权（血少时躲开高危险区）。

**七娃** — 8 岁的小学生，蹲在某个墙角。跟他说话有 **20%** 概率愿意跟你走。带走他 = 本轮立即结束（算你赢）。失败的话他会换个地方，过一会儿还能再遇到。同一个账号累计带走 **10 次**解锁称号「好爸爸」（跨轮次累计）。

**刘颖** — 一半在光里一半在暗里。她会让你选红药丸或蓝药丸，然后问你一道 ABC 单选题：

- 红药丸影响体魄类（体力/武力/魅力），蓝药丸影响心智类（魅力/智力/幸运）
- 随机影响 **1–3 个属性**，每个 ±5~20，**持续 10 分钟**
- 答对：负向概率 30%（正向 70%）
- 答错：负向概率 80%（正向 20%）
- 药效期间不会再遇到她

## 金币与商店

- 初始 **100 元**
- 18 个区块有商人（地图上标着金色圆点），只卖基础物资：绷带、止痛药、能量饮料、材料、木棍、钢管、匕首、布袋、箭矢、状态道具
- **高级武器和防具买不到**，只能从别人身上拿
- 商人收购价为原价 40%

## 玩家交易

只能和**同一区块**的玩家交易。报价式：

1. 打开交易面板，选择这个区块里的玩家
2. 左边选你给的东西 + 金币，右边选你要对方给的东西 + 金币
3. 发送报价，对方在「收到的报价」里点接受，双方物品和金币立即交换

报价 5 分钟内有效。任意一方离开区块或物品不足，交易自动取消。

## 聊天

三个频道：

- **公共** — 全服可见
- **区块** — 只有当前区块的人能看到
- **私聊** — 在输入框里以 `@玩家ID 内容` 开头即可

系统消息（开局、死亡、交易、GM 操作）会广播到公共频道。

## GM 命令

只有绑定了 GM 的账号才能用（后台「GM 权限」页绑定）。在聊天输入框里直接输入：

```
@//gm/ show me the money        金币 +10000
@//gm/ god bless you            切换无敌（免疫一切伤害）
@//gm/ give me 绷带 5            获得物品，不给数量默认 1 件
@//gm/ give me 火箭筒
```

物品名支持中文名、英文 id、模糊匹配。

## 后台管理

`/admin.html`，密码在 `store/admin.json`（默认 `jianghan`）。

五个页面：

**玩家** — 所有角色列表，点一行展开编辑：角色名、血量、精力、金币、所在区块、存活、五维属性、无敌、重置场景状态；背包可增删任何物品、清空背包或清空全部装备。

**轮次** — 开始 / 提前结束本轮，全服广播，历史轮次记录（结束原因、胜者、前三名）。

**运行** — 12 项运行指标（账号数、角色数、本轮人数、存活/出局、本轮击杀与金币、聊天条数、存档大小、内存、运行时长、Node 版本）；本轮玩家区块分布热力条；批量操作（全服满血复活 / 发金币 / 发物品 / 开无敌 / 关无敌 / 清空本轮所有存档）；聊天记录查看与清空。

**数值** — 四组共 14 个可调参数，全部即时生效：

| 组     | 参数                            |
| ----- | ----------------------------- |
| 掉落与收益 | 掉落倍率、金币收益倍率、商人价格倍率、初始金币       |
| 行动与节奏 | 移动精力消耗、探索精力消耗、状态持续时间、七娃跟随概率   |
| 战斗与危险 | 遭遇概率倍率、地雷伤害倍率、BOSS 血量、BOSS 攻击 |
| 开关    | 玩家可否自动开轮、是否启用最终 BOSS          |

外加修改管理员密码。

## 界面布局

三栏：

## 视觉与美术

**主题**：黑底 + 暗红。主色 `#c8453a`，不是鲜红，是带灰的质感红，跟黑底搭。

**像素立绘**：所有角色（敌人、NPC、人质、七娃、刘颖、主角）都是程序化绘制的像素小人，不依赖任何图片文件。主角会随穿戴的装备（头盔、护甲、武器）和状态（醉、清醒、中毒、冻结）改变外观和表情。

**物品图标**：137 件物品全部有 24×24 像素图标，按类型分派形状（枪/刀/甲/瓶/弹/炸弹…），边框颜色对应稀有度。

**两个特殊角色的立绘是单独做的**，分辨率是普通角色的 4 倍（48×64 网格），带渐变光效、地面投影和多层明暗：

- **七娃**：暖黄背光，大脑袋小身体，蓝校服 + 橙书包带 + 红领巾，手里攥着半块饼干
- **刘颖**：整幅立绘直接当对话窗口的背景。左边是天使（白衣、柔光、黑发），右边是恶魔（暗红、锐利阴影、发红光的眼睛），**双手平伸托着两颗药丸**——左手红、右手蓝

**背包分类**：背包顶部有分类 tab（全部/装备/药物/材料/弹药/其他），每类显示数量，点一下只看这一类。

## 战斗

<img src="docs/img/battle.png" alt="战斗界面" width="100%">

<p align="center"><sub>左边是你，右边是那个落单的学生。下面那行字会说清楚谁打中了谁、掉了多少血</sub></p>

- 伤害 = 武器伤害 ×(1 + 武力/150) × 随机系数 × 防御减伤 × 状态系数
- 防御递减减伤（`100/(100+防御×2.5)`），不会出现完全免疫
- 暴击率 = 8% + 幸运×0.25%

**自动攻击**：战斗界面有勾选框。勾上之后每 0.65 秒自动攻击一次，血量低于 25% 自动停手；不勾就每步手动决定，界面会提示当前是哪种模式。

**噪音机制**：冷兵器噪音 1–3，几乎无声；枪械噪音 8–10。开枪后战斗结束有概率立刻引来下一波（最多 3 连战）。弓箭/弩噪音 1，不触发连续遭遇。

## 武器 / 防具 / 背包 / 合成

- **22 把武器**（全部现实存在）：冷兵器 11 把（匕首、砍刀、消防斧、棒球棍、铁锤、长矛、弓、弩、弹弓、鱼叉、电击棍）+ 火器 11 把（信号枪、54式/92式/左轮手枪、双管猎枪、79式冲锋枪、95式自动步枪、56式半自动、88式狙击、95式班用机枪、40 火箭筒）
- **29 件防具**，6 个部位：头盔、装甲、手套、裤子、面具、鞋子
- **5 种背包**：布袋 +8 / 帆布包 +20 / 登山包 +40 / 军用背包 +60 / 战术背囊 +100（总 132 格）
- **80 条合成配方**：武器 21 / 防具 20 / 弹药 12 / 暗器 8 / 医疗 7 / 配件 7 / 背包 5

合成成功率 = 30 + 智力×0.7 − 难度×8，智力满 100 必定成功。失败材料全毁。

### 背包操作

- **分类页签**：全部 / 装备 / 药物 / 材料 / 弹药 / 其他，每类带数量
- **按类别着色**：格子的底色和虚线边框区分物品种类，背包顶部有一行图例

| 类别 | 颜色 |
|---|---|
| 武器 | 浅红 |
| 防具 | 浅蓝 |
| 背包 | 浅棕 |
| 药物 | 浅绿 |
| 暗器 | 浅橙 |
| 弹药 | 浅黄 |
| 材料 | 浅灰棕 |
| 配件 | 浅紫 |
| 特殊 | 浅金 |

- **整理按钮**：右上角「整理」，一键把同类物品排到一起（顺序：武器→防具→背包→药物→暗器→弹药→材料→配件→特殊），同类里稀有度高的在前
- **同类合并**：堆叠上限拆成多格的同类物品合并显示成一格（绷带 x9），不会出现两格「绷带」
- **批量使用**：药物类点开后有一个红色滑块，默认 1，拖动选一次用几个，按钮实时显示「使用 N 个」
- 状态类（二锅头/毒蘑菇）和解除类（解毒剂）用多个只会覆盖状态，强制 1 个
- 投掷物在背包里没有目标，用不了
- 装备按钮会显示「装备 / 更换 / 已装备」三种状态

### 合成红点

材料凑齐、智力够的时候，「合成」按钮右上角会亮一个小圆点：

- **红点** = 能合成装备类（武器 / 防具 / 背包 / 配件）
- **绿点** = 只能合成消耗类（医疗 / 暗器 / 弹药）

鼠标停在合成按钮上会浮出清单，告诉你具体能做什么。

点开合成台，顶部有提示条列出可合成项，点「知道了」之后圆点消失；分类页签上也有对应颜色的小点。如果某个配方因为材料用掉变得做不了，下次再凑齐时会重新提示。

## 数据结构

```
store/
  users.json          账号（salt + scrypt hash）+ GM 标记 + 跨轮次累计
  admin.json          管理员密码
  world.json          轮次状态、聊天记录、全局数值、历史榜单
  saves/<md5>.json    每个玩家一份完整存档
```

全部是纯 JSON，可以直接用编辑器改数值测试。也可以 `GET /api/export` 导出当前存档。

## 导出

- **玩家**：背包面板底部「导出 CSV」，导出自己的存档
- **后台**：「运行」页「导出全服存档 CSV」

26 列：账号、角色名、轮次、位置、存活、回合、击杀、金币、生命/精力及其上限、五维、异常状态、无敌、武器、武器耐久、称号数与称号、随行人数、唱歌次数、背包清单。

带 UTF-8 BOM，Excel 直接打开不乱码。

## 移动端

768px 以下自动切换单列布局：地图铺满宽度、底部按钮固定、弹窗变成底部抽屉。竖屏手机可直接玩。

## 自检

  api-test2.js api-test3.js api-test4.js pvp-test.js ui-test.js
